# Data Set Description

Training data comprises **42,000** corporate obligor-year observations from 2015 to 2024, sourced from audited financial statements and internal credit files.

| Period | Obligors | Default Rate |
| --- | --- | --- |
| 2015–2019 | 18,500 | 1.8% |
| 2020–2022 | 12,800 | 3.1% |
| 2023–2024 | 10,700 | 1.4% |
